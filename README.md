# Chat Assessment

Легковесный чат-клиент на Vue 3 + TypeScript с поддержкой Tailwind CSS и Pinia. Сообщения поступают по WebSocket, контакты сортируются по времени последнего сообщения, отображаются непрочитанные сообщения и адаптивная вёрстка (список контактов + диалог).

## Запуск проекта

```bash
npm install
npm run dev
```

Если `VITE_WS_URL` не задан, в локальной среде приложение подключается к `ws://localhost:8181` или `wss://localhost:8181` в зависимости от протокола страницы. Для удалённых окружений лучше явно задавать безопасный URL через переменную окружения:

```bash
VITE_WS_URL=wss://example.com npm run dev
```

Сборка продовой версии:

```bash
npm run build
```

## Тестовый WebSocket-сервер

Мини-сервер можно запустить в Docker и получать тестовые сообщения каждые 2 секунды:

```bash
docker run -p 8181:8181 ravlio/wstest:latest
```

## Архитектура (FSD)

- `src/app` — инициализация приложения, глобальные провайдеры и стили.
- `src/pages/chat` — страница чата, собирающая виджеты и подключающая процессы/фичи.
- `src/widgets` — крупные блоки UI: список контактов (`chat-contacts`) и диалог (`chat-dialog`).
- `src/features` — пользовательские сценарии (выбор контакта, отправка сообщения, авто-выбор первого контакта).
- `src/entities/chat` — доменная модель (Pinia-стор, типы контакт/сообщение).
- `src/processes/chat-connection` — процесс соединения с WebSocket.
- `src/shared` — переиспользуемые утилиты, API-клиент WebSocket, форматирование дат, медиазапросы.

Адаптивность: на широких экранах список и диалог отображаются одновременно, на узких — сперва список контактов и отдельный экран диалога с кнопкой «Назад».
